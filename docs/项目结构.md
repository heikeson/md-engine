## 八、架构特点与设计模式

- **单向管线，收发对称**：`md → AST → md` 逐字一致；容器节点在 mdast 层统一为 `jsxBlock` 自定义节点，渲染时由 hast handler 转换，序列化由 toMarkdown handler 输出。
- **分层架构（模块边界硬约束）**：
  - 声明层（registry/policy）禁止依赖 React/DOM；
  - 词法层（syntax）禁止依赖 mdast/React；
  - 渲染层必须 SSR 安全（不访问 window/document）；
  - 编辑器层不得被主入口导出（否则 CodeMirror 进入阅读页 chunk）。
- **容错降级原则**：不崩、不吞内容；未知标签交回内置 html flow，未闭合降级为文本并产出 `UNCLOSED_TAG`，超限嵌套降级为 source 块。
- **构建产物发布**：`tsup` 产出 `dist/`（JS + `.d.ts` + sourcemap），三个入口相互隔离；样式 `styles/engine.css` 保留 `@apply` 源码，交由宿主 Tailwind 4 管线处理。
- **契约三约束（不可破坏性变更）**：语法只增不改（C1）、配置只增不改（C2）、样式随包走（C3）。

| 依赖 | 当前版本 | 问题 |
|------|----------|------|

### 反模式
- 无循环依赖、无幽灵依赖、无未使用依赖（基于 `src/index.ts` 与各模块 import 扫描）。

- **已发布**（2026-10-25）：`@heikeson/md-engine@0.1.0` 上线 npm（`latest`），产物为 `tsup` 构建的 `dist` + `styles`，源码不入包。发布配置（`.npmrc`/`.npmignore`/`LICENSE`/`publishConfig`/`prepublishOnly`）均已就绪，后续发版只需改版本号 + `npm publish`。详见 `docs/构建与发布.md` 与 `docs/npm发布配置/需求文档.md`。
