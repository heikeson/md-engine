## 一、现状

`<Files>` 的目录行由 `src/components/folder.tsx` 渲染，结构为原生 `<details>`（服务端可折叠、零客户端 JS）：

```16:39:src/components/folder.tsx
<details className="files-folder" open={defaultOpen}>
  <summary className="files-row files-folder-row">
    <span className="files-chevron">…ChevronIcon…</span>
    <FolderIcon />
    <span className="files-name files-folder-name">{name}</span>
    <span className="files-count">{count}</span>
  </summary>
  <div className="files-children">{children}</div>
</details>
```

问题点：

| 项 | 现状 | 结果 |
|----|------|------|
| `FolderIcon`（`src/components/files-icons.tsx`） | 只有一种闭合形态（顶部 tab + 实心浅填充 + 描边） | 展开后图标不变，仅靠左侧 chevron 旋转 90° 提示 |
| 视觉表达 | 展开的目录仍画成"合上的文件夹" | 与树形控件通用习惯不符（目录打开应呈敞口形态） |

## 二、方案对比

| 方案 | 做法 | 取舍 |
|------|------|------|
| A（选用） | 单个 SVG 内绘制两组图形（闭合 / 打开），由 CSS 依 `details[open]` 切换显隐 | 零客户端 JS、SSR 安全、无 hydration 依赖；与现有 chevron 的纯 CSS 旋转机制同源 |
| B | 在 `Folder` 中引入 React state 监听 `toggle` 事件 | 需要 `"use client"` 与事件绑定，破坏当前"零 JS 折叠"约束，且 SSR 首帧形态会闪 |
| C | 只旋转 / 缩放现有单一图标 | 不满足"开 / 关两种形态"的诉求 |

选 **方案 A**。

## 三、实施细节

### 3.1 图标（`src/components/files-icons.tsx`）

- 保留 `FolderIcon` 导出名与调用签名不变（组件内部改造，调用方零改动）。
- SVG 内改为两组 `<g>`：
  - `files-shape-closed`：现有闭合形态（原样保留，宿主观感不回退）；
  - `files-shape-open`：打开形态——后部浅填充的文件夹主体 + 前部向前下方敞开的斜盖轮廓，与闭合形态共用同一基线（底边 `y=15`）与 tab 位置，切换时"身形不跳"。
- 两组图形共用 `currentColor`，颜色仍由 `.files-folder-row` 的 `text-muted-foreground` / `hover:text-foreground` 决定。

### 3.2 切换（`styles/engine.css`）

在 Files 样式段新增两条规则（沿用 `.files-folder[open] > summary` 既有选择器形态）：

```css
.prose-site .files-folder > summary .files-shape-open { display: none; }
.prose-site .files-folder[open] > summary .files-shape-closed { display: none; }
.prose-site .files-folder[open] > summary .files-shape-open { display: inline; }
```

- 嵌套目录各自命中自己的 `<summary>`，互不干扰。
- 已知取舍：`display` 切换无过渡动画（如需淡入交叉需把两组图形绝对定位叠放，会引入定位耦合，本次不做）；开合主反馈仍由 chevron 的 `transition` 旋转承担。

### 3.3 不动的东西

| 项 | 说明 |
|----|------|
| `src/registry.ts` | 不新增属性、不改语法 → 契约 C1（语法只增不改）不受影响 |
| `src/serialize.ts` / `policy*` | 纯渲染层改动，md 文本往返结果不变 |
| `folder.tsx` / `file.tsx` | 类名、DOM 结构与对齐占位（`files-spacer` 10px）保持原样 |
| `files-children` 缩进线、`files-count` | 不变 |
