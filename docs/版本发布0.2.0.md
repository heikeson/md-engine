## 一、背景

`@heikeson/md-engine@0.1.0` 于 2026-10-25 发布到 npm（`latest`），宿主 `blog-heikeson2026` 已改为依赖 `^0.1.0`。此后本仓库在 `eaba9e4` 之后累积了 10 个提交，均**未进过 npm 包**，宿主拿不到：诊断项、URL 校验口径、数学公式往返修复、文件树图标、Callout 自定义图标等。

本次发布的目标：把这批改动一次性推向 npm，宿主只需升级版本号即可获得。

## 二、版本口径

| 项 | 值 | 依据 |
|---|---|---|
| 上一版本 | `0.1.0` | npm `latest` |
| 本次版本 | `0.2.0` | 含**新增组件属性**（`Callout icon`、`File icon`）与新导出（`rehype-safe-anchors` / `hast` 层 URL 闸门），全部向后兼容 |
| 升级类型 | `minor` | [docs/构建与发布.md](./构建与发布.md) 第七节：新增组件 / 新增可选属性 → minor |
| 破坏性变更 | 无 | 契约 C1「语法只增不改」仍成立；已发布组件的名字与属性语义未改 |

> 说明：`b60428f`（Tabs 左侧留白）本身属 patch 级样式修复，但同批含有 minor 级新能力，故按 minor 取版本。

## 三、本次更新内容（自 0.1.0 起）

按面向消费者的能力归类，括号内为提交。

### 3.1 新能力

| 能力 | 说明 | 提交 |
|---|---|---|
| `Callout` 的 `icon` 属性 | 支持字符串（emoji / 短文本）或 React 节点；无 `title` 时图标与正文同行、不补默认标签 | `0c5894e` |
| `File` 的 `icon` 属性 | 扩展名 → 12 类图标（code/text/data/image/video/audio/archive/sheet/script/lock/key/font），未命中回退自绘 `FileIcon` | `e8f7969` |
| 文件夹开合双形态图标 | 闭合 / 敞口两组图形由 `engine.css` 依 `details[open]` 互斥显示，零客户端 JS | `ad7b5b3` |
| 诊断补齐 | 新增 `UNSAFE_HREF` / `UNKNOWN_TAG`，`hast` 层 `rehype-safe-urls` 作为唯一 URL 闸门（宿主覆盖组件也绕不过） | `1ecd176` |
| `rehype-safe-anchors` | 还原锚点 percent-encoding，`href` 与 `rehype-slug` 生成的 `id` 字面一致 | `f620dd6` |
| 本地开发渲染环境 | Vite playground（5180）+ fixtures + 静态快照脚本（不进包） | `550c423` |

### 3.2 修复

| 修复 | 说明 | 提交 |
|---|---|---|
| 数学公式往返被转义 | parse / serialize 对称接入 math 扩展，`mdast-util-math`、`micromark-extension-math` 升为直接依赖 | `742bbd1` |
| 未闭合容器序列化 | `collectUnclosed` 回写 `data.closed=false`，序列化不再补闭合标签 | `56d9969` |
| Tabs 首个选项紧贴左边框 | `.tabs-header` 由 `px-0` 改 `px-3`，与正文 `p-4` 对齐 | `b60428f` |

### 3.3 行为口径调整

- **URL 校验放宽**：放行相对路径与 `//host`，仍拒绝非白名单 scheme（`javascript:` / `data:` 等）。（`b983ac3`）
- **新增直接依赖**：`mdast-util-math`、`micromark-extension-math`（原先只经 `remark-math` 传递引入）。宿主 `npm install` 会自动装，无需手工处理。
