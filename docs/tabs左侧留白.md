# Tabs 左侧留白修复

> @updated 2026-10-26 22:27

## 一、问题

宿主阅读页中 `Tabs` 组件的第一个选项（如「安装」）文字距选项卡边框仅约 4px，视觉上紧贴左边框；而下方 `.tab-panel` 正文有 `p-4`（16px）留白，两者左边界不对齐。

原因是样式层缺少水平内边距：

| 选择器 | 原值 | 结果 |
|--------|------|------|
| `.tabs-header` | `px-0 py-0` | 头部无左右内边距 |
| `.tab-btn` | `px-1` | 单个按钮仅 4px 内边距 |

第一个 tab 文字左边界 = 0 + 4 = 4px。

## 二、方案

保持「标准下划线形态」不变（无底色、无阴影），仅调整水平留白：

| 选择器 | 改为 | 说明 |
|--------|------|------|
| `.tabs-header` | `px-3` | 头部左右各 12px |
| `.tab-btn` | 保持 `px-1` | 保留按钮内边距，扩大点击热区 |

效果：tab 文字左边界 = 12 + 4 = **16px**，与 `.tab-panel` 的 `p-4` 对齐；tab 之间文字间距仍为 `gap-5(20) + 4 + 4 = 28px`，与改动前一致，不会变松。

未采用 `px-4` + `tab-btn px-0`：那样按钮宽度退化为文字宽度，点击热区变小。

## 三、影响范围

- 仅 `styles/engine.css` 的 `.tabs-header` 一行，属视觉修正，无 API / 语法 / 契约变更（C1/C2/C3 均不受影响）。
- 宿主需升级 `@heikeson/md-engine` 版本后生效（样式随包发布）。
- `src/components/tabs.tsx` 无需改动（类名不变）。

## 四、验证

- `npm run typecheck`：确认无类型回归（CSS 改动不影响）。
- 视觉：`npm run dev` 起 playground 目验「容器全量」样例的 Tabs 段；或发布后由宿主确认。
