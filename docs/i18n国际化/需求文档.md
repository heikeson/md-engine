## 一、背景

包内已有 `UIText`（33 个键，中文默认）+ `config.text` 浅合并覆写机制，但它是"单语言 + 局部补丁"，存在三处结构性缺陷：

| # | 缺陷 | 后果 |
|---|---|---|
| D1 | 语言包里放句子碎片（`editorWordCountUnit: "字"`、`editorDiagnosticPrefix: "条提示："`） | 复数与语序无法表达，英文必错 |
| D2 | 领域层（`policy.ts`/`policy-tags.ts`）就地拼中文诊断，无 Context | 诊断永远中文 |
| D3 | 语言选择与文案补丁合并成一个 `text` 字段 | 没有 locale、没有回退链，换语言要手写 33 键 |

另有 D4 `EditorConfig.placeholder` 是死配置、D5 `TYPE_MAP[].label` 是死数据、D6 `DUPLICATE_ID` 一个 code 对应两条文案。

**目标**：把"语言"从"文案补丁"里独立出来，按 ICU 标准重做消息层，让引擎与 site 都能真正双语运行，且不破坏 C1/C2/C3。

## 二、已确认决策（用户确认时间 2026-11-02 19:10 / 19:29 / 19:31）

| # | 决策 | 说明 |
|---|---|---|
| 1 | 消息语法用 **ICU + `intl-messageformat`** | 复数走 CLDR，与 react-intl 生态与 CAT 工具互通 |
| 2 | **RTL 纳入本次范围** | `styles/` 18 处物理属性 → 逻辑属性，locale 推导方向 |
| 3 | 诊断 **加 `params` + 细分 `code`** | `message` 保留为中文兜底 |
| 4 | 新增**根级 Provider** | 一次设置、全局生效；`props > Provider > localStorage > 默认` |
| 5 | 回退语言：默认中文 + **可配 `fallbackLocale`** | 日语站点可回退英文 |
| 6 | 提供 **`resolveLocale()` / `detectLocale()`** 纯函数 | 库内绝不隐式调用 |
| 7 | 持久化走 **localStorage，键 `lkes-md-lang`**，宿主可换实现 | 不走 cookie；库不主动写 |
| 8 | site **只做路由级翻译**，组件/编辑器自动识别路由语言 | 中文无前缀，英文 `/en/` |
| 9 | 英文站**先只上 `/en` 首页 + `/en/playground`** | `/en/docs` 不生成，导航隐藏英文文档入口 |
| 10 | 根路径 `/` **不按记忆自动跳转** | URL 可预测、零闪烁、SEO 干净 |

## 四、功能需求

### FR-1 消息层（ICU）

- 消息值支持 ICU 语法：`{name}` 插值、`{n, plural, one{…} other{…}}`、`{n, number, …}`。
- 提供 `formatMessage(locale, template, params)` 与 React 侧 `useMessage()` / `t(key, params)`。
- `Intl.PluralRules` / `Intl.NumberFormat` 按 locale 缓存（`Map`，纯函数映射）。
- 不支持 locale 时（small-icu）降级：文案照换，复数退化 `en`，开发模式告警。

### FR-2 语言包

- `src/locales/zh-CN.ts`、`src/locales/en-US.ts`，均 `satisfies UIText`（编译期强制全量）。
- 子路径导出 `@heikeson/md-engine/locales/en-US`；主入口只带 zh-CN。
- `DEFAULT_UI_TEXT` / `defaultUIText` 保留为 zh-CN 别名（向后兼容）。

### FR-3 解析链与回退

```
messages[key] → 内置包[locale] → 内置包[fallbackLocale ?? "zh-CN"] → 内置包["zh-CN"]
```
BCP-47 截断回退（`en-GB` → `en` → 下一级）。`fallbackLocale` 为新增可选配置。

### FR-4 根级 Provider

- `MdEngineProvider`：`locale?`、`messages?`、`fallbackLocale?`、`storage?`。
- 可嵌套：`locale` 就近覆盖，`messages` 逐键叠加。
- 内部导出 `useLocale()` → `{ locale, direction, messages, t }`。
- **无全局可变状态**，SSR 并发安全。

### FR-5 缺键补齐

| 分组 | 键 | 来源 |
|---|---|---|
| TypeTable 表头 | 属性/类型/默认值/说明 | `type-table.tsx:22-25` |
| TypeItem | 必填、空占位 `—` | `type-item.tsx:33,36,38` |
| 编辑器块插入 | `插入 {name}`（模板，标识符不翻译） | `MarkdownEditor.tsx:258-267` |
| 编辑器占位符 | `editorPlaceholder` + 包裹兜底 | `actions.ts:35`、`codemirror.ts:138` |

### FR-6 诊断结构化

- `Diagnostic.params?: Record<string, string | number>`。
- `DUPLICATE_ID` 拆为 `DUPLICATE_ID_ANCHOR` / `DUPLICATE_ID_DIV`；旧码保留在联合类型中（`@deprecated`，不再产出）。
- 10 条诊断进入消息表（`diag*` 前缀），展示层用 `code + params` 渲染，无对应键时回退 `message`。
- 领域层**不 import 任何文案表**。

### FR-7 编辑器

- 新增 `EditorConfig.locale` / `messages`；`rendererConfig` 透传一致。
- `config.placeholder` 接线（优先级：`config.placeholder` > `messages.editorPlaceholder` > 默认）。
- **重建依赖修正**：`MarkdownEditor.tsx:200` 的 `text.editorWrapPlaceholder` 移出依赖数组，placeholder 走 `Compartment.reconfigure()` 或 ref 通道。
- locale 切换不得重置光标、选区、滚动、撤销栈。

### FR-8 持久化

- `DEFAULT_LOCALE_STORAGE_KEY = "lkes-md-lang"`。
- `createLocaleStorage({ key?, get?, set?, remove? })`，默认实现封装 localStorage；非浏览器环境 `get()` 返回 `null`、`set()` 空操作。
- 库**不主动写**；仅当 `props` / `Provider` 都未给 locale 时，客户端挂载后读一次。
- `toRouteSegment()` / `fromRouteSegment()` 做「`zh-CN` ↔ `zh`」转换。

### FR-9 方向（RTL）

- `isRTL(locale)` 识别 `ar`/`he`/`fa`/`ur`；`useLocale()` 暴露 `direction`。
- `styles/` 18 处物理属性迁移逻辑属性（`margin/padding/border-inline-*`、`inset-inline-*`、`text-align: start`）。
- **库不输出 `dir` 属性**，依赖宿主 `<html dir>` + 逻辑属性。
- Mermaid 图表内容不镜像。

### FR-10 旧键收口

- 新增 `editorWordCount` / `editorDiagnostic` 完整模板键。
- 旧键保留并标 `@deprecated`；单向投影：宿主只覆写旧键时按旧值组装，输出与现状逐字一致。
- 下一大版本移除。

### FR-11 site 路由

- `splitLocale(path)` → `{ locale, path }`；中文无前缀、英文 `/en/`。
- `useLocalePath()` 统一提供剥前缀后的 path（修 `Header.tsx:46` 的 `startsWith("/docs")` 失效问题）。
- `Link` 自动拼当前语言前缀（外链/绝对 URL 不拼）。
- `App.tsx` 单点注入 `<MdEngineProvider>`，4 个调用点零改动。
- `entry-server.tsx` 的 `PAGES` 加倍（`/en`、`/en/playground`，不含 `/en/docs`）。
- `prerender.mjs` 的 `withMeta` 增加 `<html lang>` 替换；404 保持中文单份。
- Header 增加语言切换器：写 `lkes-md-lang` + 跳到对应前缀 URL，选中态跟 URL 走。

### FR-12 site 文案

- 新增 `SITE_MESSAGES`（zh-CN / en-US），替换 ~90 处硬编码（Header ~17、Footer ~19、DocsLayout ~13、Home ~30、Playground ~20、NotFound 4、CodeBlock 2、标题模板 ~10）。
- 英文首页 `HERO_MD` / `PACK_MD` 与 Playground 英文样例内容同步提供。
- `highlight.ts:187` 的 `"TEXT"` 不翻译。

## 五、非功能需求

| 项 | 要求 |
|---|---|
| SSR 安全 | 主入口顶层不访问 `window`/`document`/`navigator`；`renderToString` 可跑 |
| 契约 | C1/C2/C3 只增不改；`对接契约.md` 同步；`update.md` 记录 |
| 零回归 | 默认 locale 下 `npm run snapshot` 输出逐字不变 |
| 语法隔离 | `parse()` / `roundtrip()` 结果与 locale 无关 |
| 性能 | Provider 解析结果 memo；语言包必须是模块级常量（`useShallowStable` 不被击穿）；locale 切换不重建 CodeMirror |
| 无隐式探测 | 库不读 navigator / html[lang] / cookie / header |
