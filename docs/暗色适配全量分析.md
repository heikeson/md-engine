## 一、结论先行

| 项 | 结论 |
|---|---|
| 症状 | 暗色页面下 Accordion 纯白底、TypeTable 内联块白底、Cards/Steps 白边、Files 文字偏暗 |
| 根因 | **令牌层**：`--lkes-*` 在 `:root` 用 `var(--宿主变量, 兜底)` 定义，自定义属性的 `var()` 在声明处就替换并**固化**，`.dark` 之后再改宿主变量影响不到它；且宿主缺这些变量时直接落到亮色兜底 |

| 修复 | 只改 `styles/tokens.css`：令牌改为**引擎自带亮/暗两套字面量**，暗色定义在 `.dark` / `[data-theme="dark"]` 祖先作用域 |
| 为什么一处就够 | 组件样式统一用 `var(--lkes-*)`，变量在**元素上**解析；祖先加了 `.dark`，所有组件同时拿到暗色值 |

## 三、根因详解

### 3.1 CSS 自定义属性的固化

```css
/* 改前 */
:root {
  --lkes-bg: var(--background, #ffffff);   /* ← var() 在这里就替换完了 */
}
```

`:root` 上的 `--lkes-bg` 计算值是"当时的 `--background` 或 `#ffffff`"。子元素继承的是**这个已算好的值**，
宿主之后在 `.dark` 里改 `--background` 不会让 `--lkes-bg` 重算。这与图表那次踩的是同一个坑
（见 `md-engine-交互式Mermaid集成设计方案.md` 附录第 23 条）。

### 3.2 三重放大

| 放大因素 | 表现 |
|---|---|
| 宿主把 `.dark` 挂在非 `html` 元素（如 `<div class="dark">`） | 连 `html.dark` 都匹配不到 |
| 宿主未定义 `.dark` 下的 `--card` / `--muted` 等 | 直接落到亮色兜底 `#ffffff` / `#f3f4f6` |
| 引擎侧 0 处暗色规则 | 没有任何"自愈"路径 |

## 四、修复

### 4.1 改动（唯一文件：`styles/tokens.css`）

```css
@layer lkes.tokens {
  /* 亮色：字面量，不引用宿主任何变量 */
  :root {
    --lkes-bg: #ffffff;      --lkes-fg: #1f2937;      --lkes-muted: #6b7280;
    --lkes-fill: #f3f4f6;    --lkes-border: #e5e7eb;
    --lkes-accent: #0f766e;  --lkes-ring: #0f766e;
    --lkes-radius: 0.5rem;   --lkes-overlay: rgb(0 0 0 / 0.8);
  }

  /* 暗色：祖先带 .dark 或 [data-theme="dark"] 即生效 */
  .dark,
  [data-theme="dark"] {
    --lkes-bg: #0f1419;      --lkes-fg: #e8eef2;      --lkes-muted: #9aa8b0;
    --lkes-fill: #1a222a;    --lkes-border: #232c34;
    --lkes-accent: #19d3c5;  --lkes-ring: #19d3c5;
    --lkes-overlay: rgb(0 0 0 / 0.85);
  }
}
```

要点：

1. **字面量而非 var() 链** → 无固化问题。
2. **暗色块在祖先作用域** → 写在 `html`、`body`、任意布局容器上的 `.dark` 都能命中；
   同时兼容 `[data-theme="dark"]`。
3. 仍在 `@layer lkes.tokens` 内 → 宿主在未分层样式里声明同名变量依旧覆盖，契约不破。

### 4.2 覆盖矩阵

| 组件 | 依赖令牌 | 修复前（暗色页面） | 修复后 |
|---|---|---|---|
| Accordion | bg / fill / fg / muted / border / ring | 纯白卡片、白底行 | 深底 + 深色行 + 亮字 |
| TypeTable | fill / fg / muted / border | 内联块白底、表头浅灰 | 深底块 + 暗表头 |
| Cards | border / fill / accent / muted | 白边框 | 暗边框，仅悬停时描主色 |
| Steps | bg / border | 白圆底、亮连线 | 深圆底、暗连线 |
| Files | fill / fg / muted / border | 树底浅、文字偏暗 | 深树底、亮文字 |
| Tabs | border / fg / muted / accent | 亮分隔线 | 暗分隔线、主色下划线 |
| Callout | tone / fg / border | 文字随亮色 fg | 亮字 + 语义色条不变 |
| Image | muted / overlay / radius | 题注偏暗 | 亮题注 |
| 编辑器 | bg / fill / fg / border | 白底编辑器 | 深底编辑器 |

## 五、遗留与注意

| 项 | 说明 |
|---|---|
| 语义色（Callout 五色、必填红、警告橙） | 不随明暗切换，暗色下仍可读；若需要更亮的暗色变体，另加 `.dark` 内覆盖即可 |
| CodeMirror 内部主题 | `editor.css` 只管外壳；CodeMirror 的行内配色由 `codemirror.ts` 的 theme 决定，如需完全跟随暗色需单独处理（本轮未动） |
| `--lkes-overlay` | 图片灯箱遮罩，暗色下加深到 0.85 |
| 宿主想沿用自有主题 | 在未分层样式里重新声明 `--lkes-*` 即可；不再自动跟随宿主的 `--background`（这是本轮刻意的取舍：可控优先于自动） |
